# Catálogo creativo de Taste

Consulta este repertorio cuando necesites recursos concretos dentro de una dirección elegida. Conserva las 45 entradas del arsenal original —hero y 44 recursos— y los cinco arquetipos de su sección de bento, reinterpretados bajo el contrato visual de Design Pro.

Los ocho estilos de `visual-direction.md` son familias de dirección; este catálogo contiene recursos de composición e interacción. No es una lista de elementos que deban aparecer en cada interfaz.

## Cómo elegir

- **Elegible:** puede proponerse si el contenido y la tarea lo justifican. Diseña una solución específica y pruébala; la presencia en el catálogo no obliga a usarla.
- **Condicional:** necesita un contexto funcional claro y una alternativa operable; explica por qué mejora la experiencia antes de adoptarla.
- **Pedido explícito:** reproduce recursos bloqueados o un tratamiento ornamental de la familia bloqueada. Solo se usa dentro de la excepción concreta que pidió el usuario.

Ante un conflicto, prevalece la sección 2 de `SKILL.md`. Un valor alto de los controles no habilita excepciones. En todos los casos, conserva lectura, foco, touch, teclado y movimiento reducido según corresponda.

## Cinco arquetipos del bento original

Conserva los conceptos como referencias para diseñar contenido funcional o una demostración expresamente pedida. Ninguno obliga a usar bento, cinco cards, actividad ficticia o bucles.

| Arquetipo | Traducción a Design Pro |
| --- | --- |
| The Intelligent List | Lista que cambia de prioridad por una causa real. Explicar el orden y preservar selección; no autoordenarla indefinidamente mientras alguien la lee. |
| The Command Input | Entrada real de búsqueda o comandos, con ayuda y estados útiles. La escritura automática ornamental sigue bloqueada salvo pedido. |
| The Live Status | Estado real de una tarea, con avisos proporcionados. No inventar notificaciones ni usar un pulso para aparentar actividad. |
| The Wide Data Stream | Conjunto de datos o piezas relacionadas con navegación explícita. Un carrusel infinito ornamental requiere una excepción. |
| The Contextual UI / Focus Mode | Selección de contenido que revela herramientas pertinentes. El foco y la selección se conservan en touch y teclado. |

La paleta, los radios, las columnas, los pesos tipográficos y la física de estos recursos se toman de la dirección acordada. No se hereda la obligación original de fondo claro, radios enormes, resortes universales y movimiento perpetuo.
